# Roadworthy support

- **Questions, bugs and feature requests:** open an issue at https://github.com/arshdwani/roadworthy/issues.
- Include the request key or the Roadworthy page you were on, what you expected and what happened. Leave out VINs,
  plates, driver names and other personal or confidential data.
- **Common questions**
  - *Why was a recall "ruled out" for a vehicle?* The "Ruled out" tab and each request show the reason, e.g.
    "Recall covers 2.5L engines; this VIN decodes to 2.0L". Use "Open request" if you know better.
  - *A recall says "equipped with a tow hitch" and shows "Possibly affected".* The VIN doesn't record options. Add
    what you know to the vehicle's **Equipment** attribute ("tow hitch", "no tow hitch", "12-inch SYNC screen",
    "push-button start"); the next scan uses it.
  - *No Assets on my site?* Roadworthy keeps vehicles in its own register; paste them on the Vehicles tab.
- Privacy: see `PRIVACY.md`. Response target: 2 business days.
